Remote control

Antigravity

Watch and control Antigravity running on your Mac or PC.

  1. On your computer run agy --remote-control or type /remote-control inside agy. To keep it always on: agy remote-control start.
  2. Open the dashboard and sign in with the same Google account. It opens inside this app.

Claude Code

Watch and control Claude Code running on your Mac or PC.

  1. On your computer run claude --remote-control or type /remote-control inside Claude Code.
  2. To keep it always on: inside Claude Code run /config → Enable Remote Control for all sessions.
  3. Open claude.ai/code and sign in with the same Claude account (Pro or Max plan). It opens inside this app.
